# Build Status

The `catrace` project has been reconstructed in the workspace and packaged for export.

## Included

- Go module scaffold
- Core kernel and agent library
- Trace-chain implementation
- Stationary distribution and entropy rate
- Communicating class analysis
- First-passage and commute-time utilities
- Sampling and kernel-estimation helpers
- Example programs
- Basic tests/examples
- README and sanitized mathematical summary

## Important note

This sandbox does not currently provide a working Go toolchain, so the package could not be compiled or tested in-place here. The code is intended for execution in a normal Go 1.22+ environment.
